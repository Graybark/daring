# Daring Dozen sessions

**Private GM archive.** The HTML is generated from the session Markdown and reference sources; edit those sources, not `index.html`. GitHub rebuilds the page after source changes. See [private storage and Windows sync](../../PRIVATE-SYNC.md).

Open the [campaign browser](index.html) for sessions and the OneNote reference sections: Characters, Encounters, Mythology, Factions, Culture and History, and Locations.

In-game dates marked **estimated** are inferred from the surrounding sessions and elapsed time described in the notes.

For future entries, start from the [session template](_template.md) and include a verified quote or memorable moment near the top.

One file per numbered session. Sessions 1–129 transcribe the OneNote PDF archive. Its timestamps may be note creation times rather than play dates. The dates and numbers for sessions 130–132 were confirmed by the player.
